# Rattlerow Farm Sign-in

Phone web app for Rattlerow staff to sign in at farms. Sends each sign-in to the Rattlerow Visitor Book/Biosecurity Questionnaire (Google Form).

Staff details (name, reg, mobile) are kept only on each phone. Biosecurity answers are confirmed at every visit.

Farm QR codes: add the farm to the end of the address, e.g. `#barley-brigg`.
